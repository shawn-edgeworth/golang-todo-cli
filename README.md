# Todo CLI

Простое консольное приложение на Go для составление списка задач и изменения их статуса.

## Запуск

Приложение поддерживает два режима работы:
- `go run .` для непрервыной работы в косноле
- `go run . <cmd> <arg>*` для единочного выполения команды через аргументы запуска. *Аргументы нужны не для каждого команды

## Команды

- `load <filename>`, где *filename* - имя файла, лежащего в папке ../saves/ без указания типа файла. Тип файла .json. Пример: `load myTodos`
- `save <filename>`, где *filename* - имя файла для сохранения без указания типа файла. Тип файла .json. Пример: `save myTodos`
- `add <name>`, где *name* - имя задачи в кавычках "". Пример: `add  "Купить молоко"`
- `list` - выводит список всех задач и их статус
- `done <index>`, где *index* - индекс задачи в текущем списке задач. Его можно узнать с помощью команды `list`. Пример: `done 1`
- `undone <index>`, где *index* - индекс задачи в текущем списке задач. Его можно узнать с помощью команды `list`. Пример: `undone 1` 
- `exit` - завершает работу приложения. Автоматического сохранения нет.
